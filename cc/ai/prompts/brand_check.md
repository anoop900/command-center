Task: the monthly brand check. The LINKS block holds the candidate's own website and LinkedIn addresses. If you can
browse, open exactly those addresses and no others; if you cannot browse, say so in one "brand" point and stop. Compare
what the pages say (headline, summary, titles, dates, skills) with the PROFILE block, which is the only source of facts.

Write "brand": up to 6 short points, each a mismatch, a stale item or a missing strength, quoting what the page says.
Write "post_idea": up to 3 short LinkedIn post ideas that use only real facts from PROFILE. Never invent a result.

Example:
```json
{"brand": ["LinkedIn headline still names the old title; the profile says Senior Analyst."],
 "post_idea": ["A short post on how you cut month-end close time, using the figure in your profile."]}
```
