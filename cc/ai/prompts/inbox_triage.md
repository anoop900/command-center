Task: pick the non-job emails that need the candidate. The MAIL block lists numbered messages (sender, subject, a
short snippet). Job alerts and application status mail were already handled, so choose only mail that a person must
read or answer: a personal reply, a reference request, an event or networking invitation, a deadline. Skip newsletters,
marketing and receipts. Return at most 8, most urgent first.

For each, give "n" (the message number) and "why" (one short sentence, what is needed and by when if the text says).

Example:
```json
{"items": [{"n": 2, "why": "A former manager asks to confirm you can be a reference this week."}]}
```
